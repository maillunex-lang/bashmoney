# T1: каталог и рецепты

Чистый Python 3.12, без внешних зависимостей. `Catalog` содержит версию, товары, типы предприятий, оборудование и рецепты. Идентификаторы стабильны; количественные значения строго целочисленные, в базовых единицах товара. Дубли и неизвестные ссылки отвергаются с кодом ошибки. Пустые входы допускаются для добычи или сельского хозяйства; пустые выходы запрещены. Выпуск и расход партии атомарны, дробные партии не допускаются. Функция `plan_production` не изменяет склад и не начисляет деньги: это задачи других модулей. Продукция доступна следующему тику согласно гипотезе GDD. Фиксированного баланса и импортированных данных Bizmania пока нет: рецепты ниже демонстрационные, не утверждённые игровые значения.

Тесты: `python3 -m unittest discover -s tests/catalog -v`.
