# Бизнес Башкортостан

Онлайн-экономическая стратегия для Android на Godot с изометрической 3D-картой Республики Башкортостан.

Игроки создают компании, развивают торговлю и производство, организуют поставки и конкурируют в общем постоянном мире.

## Проектирование

Проект находится на этапе GDD-01. В качестве ориентира для экономических механик используется справочник https://bizmania.ru/wikihelp/; код, визуальные материалы и игровые системы разрабатываются самостоятельно.

## Технические ориентиры

- Клиент: Godot, Android, горизонтальная ориентация.
- Карта: изометрическая 3D, города Республики Башкортостан.
- Сервер: отдельный онлайн-сервис с постоянным сохранением игрового мира.
- Разработка: NEXUS PORTAL, задачи в отдельных ветках и Pull Request.

Документация, архитектура и дорожная карта будут уточняться в GDD.
