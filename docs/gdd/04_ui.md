# Мед и Нефть · Android UI

## Утверждённое
Godot, Android, изометрическая 3D-карта Башкортостана.

## Рекомендуемое
Горизонтальный адаптивный интерфейс, полноэкранный режим, safe area вырезов камер; крупные сенсорные цели; один палец перемещает карту, два масштабируют. Окончательное управление подтверждается прототипом.

## Экраны
Штаб компании: деньги, прибыль, предупреждения, ближайший расчёт.
Карта: город, здания, участки, спрос и конкуренты.
Предприятия: отрасль, прибыль, загрузка, запасы.
Карточка предприятия: производство, закупки, сотрудники, цены, отчёт.
Поставщики: итоговая цена с доставкой, качество, срок, наличие.
Рынок: предложения, заявки, контракты.
Позже: исследования, финансы, корпорации, город.

## UX-правила
Показывать причины остановки: «нет сырья», «цена выше лимита», «квалификация ниже требований». Не прятать критичные действия в hover. На телефоне вместо широких таблиц использовать карточки и раскрываемые детали. Карта не должна требовать симуляции каждого жителя как 3D-объекта.
