# Межмодульные контракты

Контракты отдельных модулей создаются в их задачах в пределах утверждённой зоны файлов. Базовые требования: версионирование, типы и единицы, идемпотентность команд, авторизация, обработка ошибок, тесты совместимости. В T0 каталог docs/contracts/ служит точкой входа; конкретные интерфейсы ещё не реализованы.
